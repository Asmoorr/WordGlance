Слово дня и глазки для Windhawk

1. Распакуйте ВСЮ папку в постоянное место, например Документы\WindhawkClock.
2. Откройте Start.cmd двойным щелчком. Окно можно свернуть.
   Закрытие окна останавливает помощник. Python, ключи и интернет не нужны.
3. В браузере откройте http://127.0.0.1:18743/combined — появятся глазки и слово.
4. Windhawk → Taskbar Clock Customization → Settings → Web content items.
   Замените URL ПЕРВОГО существующего элемента (бывшие новости) на:
   http://127.0.0.1:18743/combined
   Web content block start, Web content start, Web content end: ОЧИСТИТЬ.
   Content mode: Plain text.
   Web content maximum length: 40.
5. Добавьте ВТОРОЙ элемент:
   URL: http://127.0.0.1:18743/meaning
   Все три границы поиска: пусто. Content mode: Plain text. Max length: 100.
6. Bottom line: %web1%
   Tooltip extra line: %web2_full%
   Web content update interval: 1 (минута).
   Top line и форматы даты/времени оставьте своими.
7. Сохраните настройки. Если старые данные остались, выключите и включите мод.

Первый/второй означают порядок ВСЕХ элементов Web content items.
Если оставили старые источники выше, номера %webN% нужно сдвинуть.
Во всех строках уберите %weather% и ненужные %webN%, чтобы они не использовались.
Старые ненужные URL можно заменить локальными адресами, чтобы не опрашивать внешние сайты.

Варианты первого URL:
http://127.0.0.1:18743/word       — только английское слово
http://127.0.0.1:18743/eyes       — только глазки
http://127.0.0.1:18743/combined   — глазки · слово
http://127.0.0.1:18743/meaning    — слово — перевод

Глазки (по местным часам компьютера):
00:00–05:59  －_－
06:00–08:59  ◔_◔
09:00–17:59  ◉_◉
18:00–21:59  ᵔ_ᵔ
22:00–23:59  －_－
Это смена выражения по времени суток, не плавная анимация.
Windhawk обновляет строку примерно раз в минуту.

Слова:
60 английских слов с кратким переводом в words.csv.
Новое слово каждый календарный день; после 60 дней цикл повторяется.
Не сервис словаря: локальный редактируемый список.
words.csv можно редактировать в Блокноте (UTF-8); после правок перезапустите помощник.
Изменение количества строк меняет соответствие слов датам.

Автозапуск, если понравится:
Создайте ярлык Start.cmd. В свойствах ярлыка задайте «Окно: Свернутое в значок».
Win+R → shell:startup → поместите туда ярлык.
Автозапуск не установлен автоматически.
Чтобы отключить — уберите ярлык из этой папки.

Если не работает:
- Не запускайте Start.cmd дважды. Если порт занят, сначала найдите старое окно помощника.
- Если символы глаз не видны, используйте для нижней строки Segoe UI Symbol.
- Если браузер показывает текст, а мод пуст: проверьте номера источников и ПУСТЫЕ границы поиска.
- Запуск не требует администратора; сервис слушает только 127.0.0.1.
