Подключить к Windhawk
  1. Открой Taskbar Clock Customization, затем Settings → Web content items.
  2. У первого источника укажи адрес этой страницы и границы из таблицы. Второй источник используй для перевода.
  3. В обоих источниках оставь Web content block start пустым. Content mode: HTML. Максимальная длина: 50 для первого, 300 для второго.
  4. Bottom line: %web1%. Tooltip extra line: %web2_full%. Web content update interval: 1 минута.
  5. Сохрани настройки. Номера web1/web2 зависят от порядка источников; замени старые источники, а не добавляй новые после них.

Открывать слово из любого приложения

Сочетание Ctrl+Alt+Win+W открывает текущее слово в Cambridge. Обработчик клавиши и WordGlance запускаются в фоне при входе в Windows.

Сочетание обрабатывает отдельный фоновый процесс в твоём сеансе. Помощник должен работать, чтобы определить текущее слово. Ошибки регистрации записываются в logs/hotkey.log.

Без горячей клавиши: открой Open-Cambridge.cmd или используй кнопку на этой странице. Для отключения сочетания останови задачу «WordGlance — горячая клавиша Cambridge» в Планировщике Windows.
